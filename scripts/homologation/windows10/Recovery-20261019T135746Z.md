É necessário identificar localmente essa falha secundária na mensagem do journal; não concluir que o estado é falso só pelas flags. Não compartilhar a mensagem livre sem revisão de dados sensíveis.

## 1. Inventário somente leitura no servidor

O administrador pode executar no Windows PowerShell 5.1. O bloco não executa a recuperação. Qualquer divergência interrompe a análise para revisão.

```powershell
$ErrorActionPreference = 'Stop'
$Root = 'C:\ProgramData\GestorOS\homologation'
$UpdateId = '20261019T135746Z-22703eaa0abd437785a28432e975bace'
$Backup = Join-Path $Root ('updates\backup-' + $UpdateId)
$Stage = Join-Path $Root ('updates\stage-' + $UpdateId)
$JournalPath = Join-Path $Backup 'journal.json'
function Assert-DiagnosticPath {
  param([string]$Path)
  $cursor = [IO.Path]::GetFullPath($Path)
  while (-not [string]::IsNullOrWhiteSpace($cursor)) {
    if ((Test-Path -LiteralPath $cursor) -and ((Get-Item -LiteralPath $cursor -Force).Attributes -band [IO.FileAttributes]::ReparsePoint)) { throw 'Caminho contém reparse point; diagnóstico interrompido.' }
    $parent = Split-Path -Parent $cursor
    if ($parent -eq $cursor) { break }
    $cursor = $parent
  }
}
Assert-DiagnosticPath $JournalPath
$Journal = [IO.File]::ReadAllText($JournalPath) | ConvertFrom-Json
if ($Journal.application -cne 'Sistema Gestor OS' -or $Journal.environment -cne 'homologation') { throw 'Journal inesperado.' }
$ExpectedNames = @('backend', 'frontend/dist', 'frontend/build-info.json')
if ((@($Journal.artifacts | ForEach-Object { $_.name }) -join ';') -cne ($ExpectedNames -join ';')) { throw 'Conjunto de artefatos inesperado.' }
Get-FileHash -LiteralPath $JournalPath -Algorithm SHA256
[pscustomobject]@{ Status = $Journal.status; SourceCommit = $Journal.sourceCommit; UpdatedAtUtc = $Journal.updatedAtUtc }
foreach ($item in $Journal.artifacts) {
  $relative = $item.name -replace '/', '\'
  $target = Join-Path $Root $relative
  $saved = Join-Path $Backup $relative
  $prepared = Join-Path $Stage $relative
  $failed = Join-Path (Join-Path $Backup 'failed-new') $relative
  foreach ($path in @($target, $saved, $prepared, $failed)) { Assert-DiagnosticPath $path }
  if ([IO.Path]::GetFullPath($item.target) -ine [IO.Path]::GetFullPath($target) -or
      [IO.Path]::GetFullPath($item.backup) -ine [IO.Path]::GetFullPath($saved) -or
      [IO.Path]::GetFullPath($item.failedNew) -ine [IO.Path]::GetFullPath($failed)) { throw 'Caminhos do journal divergem dos caminhos esperados.' }
  [pscustomobject]@{
    Artifact = $item.name; ActiveExists = (Test-Path -LiteralPath $target)
    BackupExists = (Test-Path -LiteralPath $saved); StageExists = (Test-Path -LiteralPath $prepared)
    FailedNewExists = (Test-Path -LiteralPath $failed)
    PreviousMoved = $item.previousMovedToBackup; NewActive = $item.newArtifactActive; PreviousRestored = $item.previousRestored
  }
}
foreach ($part in @('backend', ('updates\stage-' + $UpdateId + '\backend'))) {
  foreach ($dependency in @('@prisma/client', '@prisma/adapter-mariadb', 'prisma')) {
    $path = Join-Path $Root ($part + '\node_modules\' + ($dependency -replace '/', '\') + '\package.json')
    Assert-DiagnosticPath $path
    if (Test-Path -LiteralPath $path -PathType Leaf) {
      $package = [IO.File]::ReadAllText($path) | ConvertFrom-Json
      [pscustomobject]@{ Location = $part; Dependency = $dependency; Version = $package.version }
    } else { [pscustomobject]@{ Location = $part; Dependency = $dependency; Version = 'ausente' } }
  }
}
$BuildInfo = Join-Path $Root 'frontend\build-info.json'
Assert-DiagnosticPath $BuildInfo
$Frontend = [IO.File]::ReadAllText($BuildInfo) | ConvertFrom-Json
[pscustomobject]@{ FrontendEnvironment = $Frontend.environment; FrontendCommit = $Frontend.sourceCommit; FrontendVersion = $Frontend.frontendVersion }
Get-FileHash -LiteralPath $BuildInfo -Algorithm SHA256
Get-CimInstance Win32_Service -Filter "Name='GestorOSBackendHomologation' OR Name='GestorOSCaddyHomologation'" |
  Select-Object Name, State, StartName, ProcessId
Get-NetTCPConnection -State Listen -LocalPort 3100,443 -ErrorAction SilentlyContinue |
  Select-Object LocalAddress, LocalPort, OwningProcess
```

Conferir também, em Gerenciador de Tarefas ou ferramenta administrativa, se ainda existe atualizador em execução. Não imprimir linhas de comando de processos: podem conter dados sensíveis. A existência de um lock não prova que o processo está ativo, nem autoriza apagá-lo.

## 2. Validação da versão anterior

- Confirmar Client e adapter **ativos** 7.10.0; CLI 7.10.0, se instalado. A ausência do CLI no novo pacote runtime é esperada.
- Confirmar Frontend ativo em homologation, commit completo começando por `07376033`, e comparar seus arquivos com um artefato anterior confiável ou hashes registrados antes da tentativa. Metadados isolados não comprovam todos os bytes.
- Confirmar os três destinos ativos, ausência de artefatos anteriores nos caminhos de backup e ausência de `failed-new`, além do staging novo preservado. Se houver qualquer movimentação aparente, não concluir que a falha foi anterior à troca.
- Conferir a conta `NT AUTHORITY\LocalService`, estado dos dois serviços e portas. Se estiverem ativos e a versão anterior for comprovada, não interrompê-los apenas para “refazer rollback”.
- Validar no navegador o Frontend anterior e, pelo HTTPS confiável, a API sem autenticação. Estes comandos de leitura esperam 200 HTML e 401 JSON, respectivamente; não usar `-k` para ignorar TLS:

```powershell
$FrontendResponse = @(& curl.exe --silent --show-error --noproxy '*' --connect-timeout 5 --max-time 15 --resolve 'gestor-os.home.arpa:443:127.0.0.1' --output NUL --write-out '%{http_code}|%{content_type}' 'https://gestor-os.home.arpa/')
if ($LASTEXITCODE -ne 0 -or ($FrontendResponse -join '') -notmatch '^200\|text/html') { throw 'Verificação HTTPS do Frontend falhou.' }
$ApiResponse = @(& curl.exe --silent --show-error --noproxy '*' --connect-timeout 5 --max-time 15 --resolve 'gestor-os.home.arpa:443:127.0.0.1' --output NUL --write-out '%{http_code}|%{content_type}' 'https://gestor-os.home.arpa/api/v1/auth/me')
if ($LASTEXITCODE -ne 0 -or ($ApiResponse -join '') -notmatch '^401\|application/json') { throw 'Verificação HTTPS da API falhou.' }
```

Se faltarem hashes confiáveis para provar a versão anterior inteira, registrar essa limitação e manter a recuperação pendente. O journal antigo não possui os novos fingerprints. Não preencher retroativamente fingerprints a partir de arquivos de identidade desconhecida.

3. **Arquivos movidos, componentes misturados, backup ausente ou identidade incerta:** manter a recuperação bloqueada e elaborar plano por artefato, com hashes, ACLs, dependências e destino de preservação. Obter autorização antes de parar serviços ou renomear qualquer arquivo. Não aplicar uma restauração integral por cima de componentes já restaurados.
